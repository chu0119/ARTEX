## 六、安全标记（记录，不阻塞发版）

1. JWT 接受 URL query 传参且**对所有端点生效**（auth.go:265，为 SSE 服务）——建议限 SSE 路径，token 不落访问日志
2. 无 CSP / HSTS（securityHeaders，server.go:4016-4028；HTTPS 终止在前置时 HSTS 由反代加）
3. JWT 双存储（localStorage + 非 HttpOnly cookie，api.ts:107-110）——有 CSP 后风险可控
4. 强能力端点（custom 工具=任意代码、hostenv 装包、update/apply、listeners 启停）单管理员模型下预期可用，但值得在 UI 加二次确认（与 F1 同批）
5. hostd 入队去重只做了单请求内 seen（hostenv_api.go:189），跨请求 queued/running 同工具不去重（PM B6）
6. /api/auth/status 免鉴权回显初始化状态（代码注释自知，低风险保留）
